# 💪 FitBuddy – AI Fitness Plan Generator

FitBuddy is an AI-powered fitness web application that uses Google Gemini AI to generate personalized 7-day workout and food plans.

## 📌 Project Topics

1. **Prerequisites**
   - Python
   - VS Code
   - Git & GitHub

2. **Project Workflow**
   - User enters fitness details
   - Gemini generates a personalized plan
   - User can give feedback
   - AI updates the plan

3. **Model Selection and Architecture**
   - Google Gemini AI
   - FastAPI backend
   - SQLite database

4. **Development Environment**
   - Python virtual environment
   - Required Python packages
   - Gemini API key

5. **Core Functionalities**
   - User profile
   - Workout generation
   - Food plan generation
   - Health-aware planning
   - Feedback-based updates

6. **FastAPI Backend**
   - API routes
   - Database connection
   - Gemini integration

7. **Frontend Development**
   - HTML
   - CSS
   - Jinja2 templates

8. **Dynamic Templates**
   - User input page
   - Personalized result page
   - Admin dashboard

9. **Deployment**
   - GitHub repository
   - Cloud deployment

10. **Testing**
   - Test user input
   - Test AI plan generation
   - Test feedback and plan updates

## 🛠️ Technologies
